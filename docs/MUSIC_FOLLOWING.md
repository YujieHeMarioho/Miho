# 人声、延音与伴奏律动

2026-10-02，v0.8.0。用户要求动作幅度明显对应人声强弱，结合鼓点，并加入彩色音波背景。本版移除长音保留历史音量峰值的做法，以当前人声包络控制身体大小和动作幅度，频谱与流线直接呈现同一声音输入。

## 本版的动作优先级

1. 分离后人声的全频段包络驱动短句起落、身体俯仰与动作力度，缺少稳定音高的气声和音节也参与。
2. 有可靠周期性时，分析音高上扬／回落和长音。延音保留舒展方向，当前音量决定幅度；重复起音重置延音计时，避免同音高的连续说唱累积成一个长音。
3. 伴奏拍子不另起演唱时的身体循环，分离后的实际鼓点则可有限叠加：普通短句最多取鼓点力度的 30%，可靠延音时继续减轻，换气时取更小比例。重音短促加力后回到当前姿态。
4. 无人声时，保留节拍模型驱动的小幅伴奏动作，其目标幅度缩至旧版的 30%。所有姿态仍经过速度、加速度约束。

姿态跟随声音的连续特征，没有固定时长的舞步组合；侧向姿态只在真实新唱句开始时选择方向。模型不理解歌词或歌手的表演意图。

## 音量与彩色音波

人声包络用固定参考与幂曲线放大轻重差别；不按每句峰值归一化，也不把旧的最大音量当作长音下限。整体等比缩放连同耳机、墨镜一起变化，保持球形；位移、转动和缩放仍使用受限惯性。

参考 [DSWaveformImage](https://github.com/dmrschmidt/DSWaveformImage) 的实时包络与绝对音量绘制概念，以及 [Apple 的频谱可视化示例](https://developer.apple.com/documentation/accelerate/visualizing-sound-as-an-audio-spectrogram)，用自有 SwiftUI Canvas 绘制背景。现有 Hann FFT 同时提供 24 段频谱；青色和粉色流线显示最近约 3.2 秒的人声与鼓声音量包络。所有动效均来自声音标量和频谱，不用随机条柱或自行运行的节拍动画。只保存短暂、有界数据，不新增捕获源或网络运行服务。

## 实际接入

- [BeatNet](https://github.com/mjhydri/BeatNet)：实际使用预训练 CRNN，转换为显式传入／传出两层 LSTM 状态的 ONNX 图，在 Mac 原生 CPU 上运行。每 20 ms 输入 272 维特征，输出普通拍、强拍和非拍概率。保留训练时 1411 点 Hann FFT、136 个对数频率滤波器和正谱差分，使用过去的 64 ms 音频，无未来采样。
- Miho 的因果解码器：用最多 8 秒的**标量概率**估计周期和相位；结合自相关与拍点的圆周一致性，避免只看相关性导致总选半速。相位继续前进，检测结果平滑校正，节奏变化需要持续证据。它是本项目实现，不声称运行了上游粒子滤波器。
- [StemgenRT-5.8](https://github.com/sweetspotsoundsystem/StemgenRT-5.8)：实际运行人声／鼓点分离模型。人声包络、唱腔、延音和重音来自分离后的人声声部，模型仍可能漏入伴奏。
- `Choreographer`：人声决定主要姿态，不再削弱唱腔幅度给鼓点循环让位。无人声时才使用连续的伴奏点头和更慢的重心移动；没有定时轮换舞步片段。

这里的“跟踪到的拍子”可能与乐谱的半速／倍速读法不同。模型不是歌词理解、歌手身份识别或完整人体 AI 编舞。

## 行为研究如何用于角色

[Visual tuning and metrical perception of realistic point-light dance movements](https://www.nature.com/articles/srep22774) 使用身体的拍级弹动和更慢的侧向动作研究舞蹈节律。[Keeping the Beat](https://pmc.ncbi.nlm.nih.gov/articles/PMC4966945/) 比较随音乐弹动和鼓掌的同步行为。[现场音乐实验](https://pubmed.ncbi.nlm.nih.gov/36347227/) 发现低频声音影响观众运动。

此前由这些研究得到的设计判断是：给主要部件共享的节拍，慢一些换重心，低频和重音改变力度。v0.7 将这一做法限制在无人声的伴奏部分，演唱期间优先采用用户要求的人声特征。球形角色没有人体膝、髋、肩的完整骨架，因此以身体位移、俯仰和转动表达这些关系。这是设计应用，不能宣称完全复制真人舞者动作。

伴奏的惯性滤波会带来相位滞后，因此伴奏目标轨迹按滤波器响应提前，并检查**最终姿态**是否落在拍点上。人声动作直接跟随包络与唱腔，不凭伴奏相位猜测下一个音节；速度和加速度限制用于抑制突然跳变。

## 其他模型的取舍

| 项目 | 能力 | 本次用途 |
| --- | --- | --- |
| [Beat This!](https://github.com/CPJKU/beat_this) | Transformer 拍点／强拍识别 | 调研；没有作为持续低延迟原生输入模型接入 |
| [BEAST](https://github.com/WildHoneyPie/BEAST) | 在线节拍／强拍识别研究 | 调研；当前选择可固定下载、可转换和可验证的 BeatNet 权重 |
| [DiscoForcing](https://github.com/CurMack/DiscoForcing) | 因果全身音乐舞蹈生成 | 调研；公开演示使用 GPU 特征／模型、6 秒特征窗和显示缓冲，当前没有移植到原生 Mac 球形角色 |
| [EDGE](https://github.com/Stanford-TML/EDGE)、[LODGE](https://github.com/li-ronghui/LODGE) | 完整人体音乐舞蹈生成 | 调研；没有下载或运行它们的舞蹈模型 |

真正运行的是 BeatNet 节拍模型和 StemgenRT 分离模型，v0.7 以分离后的人声为主，BeatNet 为伴奏补充。动作由上述连续控制实现，没有把调研过的舞蹈模型列成已集成功能。

## 验证边界

测试分为独立模型／特征一致性、人声与鼓点优先级、反复起音与长音、伴奏节拍解码、最终姿态、速度与加速度限制、音乐样例文件和真实播放器。模型路径正常、合成信号测试通过，不能代替用户对真实歌曲的观感验收。最新结果和未完成项见 [VALIDATION.md](VALIDATION.md)。
